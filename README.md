# Brandon Moss | Game development portfolio

I designed enemy encounters and scripted AI behaviors for *Call of Duty: Modern Warfare III — Zombies*. My other game work includes original UEFN modes in Verse, mobile games in Unity and C#, and a solo multiplayer VR shooter built with Photon.

[Portfolio](https://bmoss3211.github.io/#/) · [Projects](https://bmoss3211.github.io/#/game-projects) · [Résumé](https://bmoss3211.github.io/#/resume)

## Development

Install dependencies with `npm install`, then run `npm run serve`. Update the pages in `src/views` and the project gallery in `src/data/GameProjectsData.ts`. Static assets live in `public`.

Run `npm run build` and publish the contents of `dist` to [the GitHub Pages repository](https://github.com/bmoss3211/bmoss3211.github.io).
