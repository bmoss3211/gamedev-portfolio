# Brandon Moss · Game development portfolio

I’m a gameplay programmer and technical designer. On *Call of Duty: Modern Warfare III — Zombies*, I designed enemy AI encounters, scripted behaviors in GSC, and debugged gameplay systems.

[Browse the portfolio](https://bmoss3211.github.io/#/) · [Open the project gallery](https://bmoss3211.github.io/#/game-projects)

## What’s in this repository

This is the Vue and TypeScript source for my portfolio website. The [project gallery data](src/data/GameProjectsData.ts) contains project descriptions, screenshots, and video links. The [page components](src/views) implement the gallery, résumé, and contact pages.

## Game development background

- **AAA gameplay** — Enemy placement, encounter flow, behavior scripting, and gameplay debugging on *Modern Warfare III — Zombies*.
- **UEFN and Verse** — Designed and programmed original game modes as the sole developer at Ghost Gaming.
- **Unity, C#, and Photon** — Built an online multiplayer VR first-person shooter solo for my Kennesaw State University capstone.
- **Unity mobile development** — Adapted cabinet slot games for touchscreen play on Android and iOS.

## Run the website locally

Install dependencies with `npm install` and start the development server with `npm run serve`. Run `npm run build` to generate the static site in `dist`. The published build lives in [bmoss3211.github.io](https://github.com/bmoss3211/bmoss3211.github.io).
